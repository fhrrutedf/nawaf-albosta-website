# موقع نواف البوسطة

موقع نواف البوسطة — مدرّب ذكاء اصطناعي من سوريا.
يعلّم أي حدا يستخدم أدوات الذكاء الاصطناعي بشغله اليومي: معلمين، مسوّقين، مدراء مشاريع، وصنّاع محتوى.

## العرض

افتح `index.html` مباشرة في المتصفح، أو فعّل GitHub Pages من إعدادات المستودع
(Settings → Pages → Branch: main) لعرض الموقع برابط عام.

## المحتوى

- من أنا (مع الصورة الشخصية)
- لمن أدرّب؟
- سلسلة «تعلّم كلود»
- مقالات مجانية
- دليل مجاني: ٥ برومبتات ذكاء اصطناعي جاهزة للنسخ
- الأسئلة الشائعة
- تواصل واتساب

الموقع حالياً بلا كورسات وبلا أسعار — محتوى مجاني فقط.
